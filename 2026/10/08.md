# Emacs
## point + mark = region
Emacs don't fundamentally think of selection as "highlight of text"
C-SPC: set the mark at the current point
C-x C-x: swap mark and point
## copy, cut and paste in Emacs
copy: save region to kill ring     M-w
cut: kill region                   C-w
paste: yank                        C-y
older clip entry: yang pop         M-y
## rectangular edit
C-x SPC
## multiple cursor		
its command has a prefix: mc/
for example: mc/mark-all-like-this
## register
C-x r SPC a : save point to register a
C-x r: prefix of register
SPC: save point to register
a: name of register
C-x r j a: jump to position a
C-x r s a: save the region to resigter a
C-x r i a: insert content in register a to the current position
C-x r w w: save the window configuration in register w
C-x r j w: restore the window configuration in w

# 电力电子
VIN ──┬── 100～220µF / 35V或50V 电解或固态电容
      ├── 22µF / 50V X7R 陶瓷
      ├── 22µF / 50V X7R 陶瓷
      ├── 1µF / 50V 陶瓷
      └── 100nF / 50V 陶瓷
各部分作用：
- 两颗 22µF：承担主要高频脉冲电流。
- 1µF、100nF：处理更高频的开关边沿。
- 100～220µF：处理电源线较长、插拔和负载变化造成的低频波动。
喔喔喔, 电容可以并联, 不同的电容处理不同的纹波, 这个思想值得学习!!!
