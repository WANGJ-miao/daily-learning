## 实现把`\(...\)` 替换成 `$...$`

使用正则替换 `\\(\(.*?\)\\)`
其中`\(`, `\)` 表示开始和结束一个捕获组

## 贪婪匹配与非贪婪匹配

.* 其中.表示任一字符, *表示重复0次或多次, 这会尽可能多的匹配, 即贪婪
.*? 中的?表示尽可能少的匹配, 即非贪婪

例如, 有这样一个文本: `a123b345b`
`a.*b` 会匹配到a123b345b
但是`a.*?b` 会匹配到a123b

## 一些常用的语法

```
| 源码         | 含义       |
| x_i          | 下标       |
| x^2          | 上标       |
| x_{i + 1}    | 多字符下标 |
| x^{n + 1}    | 多字符上标 |
| \alpha       | 希腊字母   |
| \theta       | 希腊字母   |
| \frac{a}{b}  | 分数       |
| \sqrt{x}     | 根号       |
| \dot{x}      | 一阶导数   |
| \ddot{x}     | 二阶导数   |
| \partial     | 偏导       |
| \sum_{i=1}^n | 求和       |
| int_0^1      | 积分       |
| \sin \theta  | 正弦函数   |
```

```
\boldsymbol 表示加粗, 经常用来表示向量和矩阵
```
## 矩阵

```
bmatrix: 方括号
pmatrix: 圆括号
vmatrix: 行列式
matrix: 没有括号

\begin{bmatrix} 开始一个方括号矩阵
& 表示分割不同的列
\\ 表示换到下一行
\end{matrix} 结束矩阵
```

## 多行公式对齐

```
\begin{aligned}
中间使用&表示对齐, 例如:
V_L &= L\frac{di}{dt} \\
	&= V_{\mathrm{in}}-V_{\mathrm{out}}
\end{aligned}
```
