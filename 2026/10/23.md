# emacs

## buffer functions

### important concepts

- buffer is a datatype in elisps. A buffer is a elisp object, who holds text.
- buffer name: every buffer has a unique name. 
- current buffer: There is always one buffer that is designated as the current buffer, where functions like "insert" work on.
- File buffer (aka. Visiting buffer) : a buffer that is a file. The file path is associated with the buffer.

### create buffers

- (with-temp-buffer &rest BODY), useful when dealing with large files
- (generate-new-buffer NAME), create a buffer with name. If the buffer name starts with a space, emacs will treat it as a inner buffer, not shown in buffer list, and undo is disabled (to save memory)
- (get-buffer-create NAME-OR-BUFFER), return an existing buffer, or create it

### Get (Visiting) buffer's file path

- (buffer-file-name &optional BUFFER), returns the file path of BUFFER
- [variable] buffer-file-name : the file path of current buffer

### get buffer name or buffer object

- (current-buffer) : returns the current buffer
- (buffer-name &optional BUFFER) : returns the buffer's name, current buffer by default
- (get-buffer BUFFER) : return the buffer object

### make buffer current

tips:
- When a buffer is current, editing functions operate on it.
- buffer being current does not imply visibility

- (set-buffer BUFFER-OR-NAME) : make a buffer current, but does not make it visible, and returns it.x
- (with-current-buffer BUFFER-OR-NAME &rest BODY) : temporarily make a buffer current, and eval the body. **for most of the time, I would use this function, because it takes care of switching back to the original buffer when done**
- (save-current-buffer &rest BODY) : execute BODY and then restore current buffer to what it is before this function call.

### switch to buffer

- (switch-to-buffer BUFFER-OR-NAME &optional NORECORD FORCE-SAME-WINDOW) : make the BUFFER visible to user, make it the current buffer, and fill the frame.
- (pop-to-buffer BUFFER-OR-NAME &optional ACTION NORECORD) : make BUFFER visible to user, make it current buffer
- (display-buffer BUFFER-OR-NAME &optional ACTION FRAME) : make BUFFER visible to user, but not make it current buffer. Usually, it is shown in a split pane


### write file

- (write-region START END FILENAME &optional APPEND VISIT LOCKNAME MUSTBENEW)

tips:
- if START is nil, write the whole buffer, and END is ignored. 
- if START is string, write that, and END is ignored.
- FILENAME is a file path or name relative to default-directory

- (write-file FILENAME &optional CONFIRM): write buffer content to a new file, like "save as", and open the file.

tips:
- do not use this, unless you want to show the file to the user after saving it.

- (append-to-file START END NAME)
- (save-buffer &optioinal ARGS) : a user-oriented function, bind to C-x C-s. avoid using this

### create file

- (with-temp-file FILE BODY) : create a buffer, make it current, evalutate body, and write the buffer to FILE.

### kill/delete file

- (kill-buffer &optional BUFFER-OR-NAME) : delete a buffer, dafault to current buffer.
