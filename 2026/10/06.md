# Programming Accumulation
## A verypratical need: count the number of encoder pulse
一个十分重要的嵌入式设计原则: 如果能用single-writer设计, 就尽量避免多个执行流修改同一状态
``` c
volatile uint32_t encoder_count = 0;

void Encoder_IRQHandler(void) {
    encoder_count++;
}

int main() {
    uint32_t count = encoder_count;
    encoder_count = 0;

    process(count);
}
```
这个主函数设计就不够好, main和handler同时在修改`encoder_count`, 会出现典型的race condition
可能主函数读取`encoder_count`之后, `encoder_count`清零之前, 发生中断, 导致一个脉冲信号被吃掉了
一种解决办法:
``` c
__disable_irq();

uint32_t count = encoder_count;
encoder_count = 0;

__enable_irq();

process(count);
```
另一种更好的设计: single-write
``` c
uint32_t last_count = 0;

while (1) {
    uint32_t now = encoder_count;
    u32 delta = now - last_count;
    last_count = now;
    process(delta);
}
```
