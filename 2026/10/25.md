## define-key and global-set-key

Emacs maintains several keymap , like: global-map, evil-normal-state-map, python-mode-map. Emacs'll look up the keymap in an order of precedence. 

minor-mode > major-mode > global

- (define-key KEYMAP KEY DEF &optional REMOVE)

`global-set-key` is a syntax surger for  (define-key global-map ...)

## how to check installed packages?

packages are stored in `package-user-dir`. By default, it is "~/.emacs.d/elpa"

use `/` to sort the packages
`/s` : sorted by sort status

three differrent concepts that are easy to confuse:

- Installed: The package exists on your computer.
- Loaded: Its Lisp code has been loaded into Emacs, typically using require or autoloading.
- Enabled: Its functionality has been activated, for example (evil-mode 1).
