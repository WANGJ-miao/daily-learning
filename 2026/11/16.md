# emacs

C-x = / g a : show the basic character information
C-u C-x = / C-u g a : show detailed information

## C-u in emacs

C-u runs the command universal-argument. It can provides arguments to the following command. The default argument is 4.

For some commands, just C-u by itself serves as a flag that is different in effect from any particular numeric argument.
