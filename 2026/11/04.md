# docker

# Docker Registry

A Docker Registry stores Docker images. DockerHub is a public registry that anyone can use.

## Docker objects

### image

An image is a read-only template with intructions for creating a Dokcer container

### container

a container is a runnable instance of an image.

a container is a group of processes running with isolation provided by the operating system

## create a container

`sudo docker run -it --name myubuntu ubuntu:24.04 bash`

run : create and start a container
-i : keep standard input open
-t : allocate a persudo terminal
--name : give the container a name
ubuntu:24.04 : image name and tag
bash : command to execute in the container

## what does docker download when I pull a container?

metadata and filesystem layers

## where does docker store its data?

in `/var/lib/docker/`

## how to reenter a docker?

### if a docker container is running

``` bash
sudo docker exec -it ubuntu1 bash
```

this command starts a new bash process inside the existing container

### if the container has stopped

previously run:

``` bash
sudo docker run -it --name ubuntu2 ubuntu:24.04 bash
```

To restart it and reconnect the terminal

``` bash
sudo docker start -ai ubuntu2
```

start: starts an existing stopped container
-a : attach your terminal to the terminal
-i : attaches standard input

## build the image

``` bash
sudo docker build -t my-c-program .
```

-t : my-c-program: give the image a name
. : specify the build context, which is the current directory

``` bash
sudo docker run --rm my-c-program
```

--rm: Automatically cleans up and removes the container's file system immediately after the container exits, preventing leftover stopped containers from cluttering your disk.
