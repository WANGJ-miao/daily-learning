## what is the difference between school wifi and common wifi in my home?

1. home wifi: WPA2/WPA3-Personal

Commonly, I only need to enter wifi name(SSID), wifi password, and then boom! connected.

for example: 

nmcli device wifi connect "Homewifi" password "12345678"

home wifi usually uses wpa2-personal or wpa3-personal, their characteristic is that all the users use the same wifi password.

wpa2-personal, client connect to the router with a PSK(pre-shared key), and don't need to create independent account for every account

2. school account

may adopt different way to access, because it needs to identify the user so as to manage the permission, count the traffic(流量), and control the access.

three common identification way:

| access way        | principle                              | what to offer                                   |
|-------------------|----------------------------------------|-------------------------------------------------|
| wpa2/3-personal   | similar to home-wifi                   | shared password                                 |
| wpa2/3-enterprise | use 802.1x/eap                         | school account, password, sometimes certificate |
| web portal        | connect to wifi, then login in webpage | school account, password                        |

## what is ssid and bssid? what does ifname refer to? 

### ssid(service set identifier)

ssid is the name of the wifi network

fudan campus has many AP, and they broadcast the same ssid, so I don't need to connect to another wifi name when I walk in the campus.

### bssid(basic service set identifier)

in common wifi infrustructure, bssid is usually the mac address used by certain AP

### ifname(interface name)

ifname tags the network interface on my computer

usually 

- wl: wireless lan, 无限局域网
- p0 : PCI bus 0
- s20 : PCI device 20
- f3 : PCI function 3

use `ip link` to check the network interface in my system

# i3bar

i3, i3bar, i3status are 3 different programs

i3
: the window manager
i3bar: draw the status bar
i3status: read the system status and generate status informantion

**i3status is an already written C Program**, in its source code has already realized many function modules, such as : 

- battery
- memory
- wireless
- disk
- tztime(time zone, time)

**order** tells i3status which module to enable, and in what order.

such as : order += "memory"

when **i3status** parses this line, it will recognize string memory

in linux, memory info mainly comes from `/proc/meminfo`

for example:

```
memory {
    format = "RAM: %used / %total"
}
```

`%used` and `total` are supported placeholder designed in the program in advance

check what placeholders are supported in the memory section in manual

`man i3status`

**Separation of Concerns**, i3status is responsible for data, and i3bar is responsible for display

## use linux signal to update status immediately

``` 
# in i3blocks/config
[volume]
command=wpctl get-volume @DEFAULT_AUDIO_SINK@ | awk '{print "VOL: " int($2*100) "%"}'
interval=once
signal=11

# in i3/config
set $refresh_volume pkill -RTMIN+11 -x i3blocks

bindsym XF86AudioRaiseVolume exec --no-startup-id wpctl set-volume @DEFAULT_AUDIO_SINK@ 5%+ && $refresh_volume
```

there 2 categories of signal in Linux:

1. Standard Signals

- sigint
- sigterm
- sigkill
- sigusr1
- sigusr2

2. Real-Time Signals

from sigrtmin(usually 34) to sigrtmax(usually 64)
