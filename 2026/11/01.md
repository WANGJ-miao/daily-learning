# bash scripting

## aim : automate the process of configuring the framebuffer

split the goal:

1. check whether external HDMI monitor is connected
2. if connected, execute monitors.sh
3. if not connected, execute laptop_only.sh

``` pseudocode
if hdmi id connected
:
	execute monitors.sh
else:
	execute laptop_only.sh
```

use grep to check whether HDMI is connect 

``` bash
wangj@thinkpad:~$ xrandr --query | grep "HDMI-1 connected"
HDMI-1 connected 2880x1620+0+0 (normal left inverted right x axis y axis) 598mm x 336mm
```

`grep` will return a status code, representing whether it finds something. If not it returns 0, if it does, it returns 1.

So, I can write :

``` bash
if xrandr --query | grep -q "^HDMI-1 connected"; then
	echo "External monitor detected!"
else
	echo "Laptop screen only"
fi
```

`-q` means quiet, grep will not print anything
`^` is the line start anchor

BASH_SOURCE is a special array in bash

BASH_SOURCE stores the path of the executing script.

`dirname` extracts the directory name part of the path

for example:

``` bash 
dirname -- "${BASH_SOURCE[0]}"
```

## " in bash

" in bash doesn't mean a string, instead it tells Shell to consider things in " as a whole and do not do word splitting or pathname expansion

# emacs

`tab-width` controls the display width of actual tab char
`indent-tabs-mode` controls whether tabs are used for indentation.

the number of spaces used for indentation is often determined by the programming language's major mode

for example: in python uses:

``` emacs-lisp
(setq python-indent-offset 4)
```

in c/c++ use:

``` c
(setq-default c-base-offset 4)
```
