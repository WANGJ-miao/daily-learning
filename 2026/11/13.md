|--------------------------|------------------------------|

# how to set the color of the prompt?

`PS1='\[\e[1;32m\]\u@\h:\w\$ \[\3[0m\]' `

`\[` and `\]` means the characters inside don't occupy any visible columns, which is important for correct cursor positioning.

`\e`: the ESC character

`[1;32m` : an ANSI SGR sequence that enables bold text and sets the foreground color to green.

`\e[0m` : Reset all text formatting

# scratchpad

there's a invisible workspace called scratch workspace. I can put certain window into this workspace, and it becomes a scratchpad.

I can make a window a scratch pad using `move scratchpad`

``` bash
i3-msg 'move scratchpad'
```

I can display the first scratchpad window using `scratchpad show`. this msg support toggling. If `scratchpad show` to a shown window, it will becomes a scratchpad.

``` bash
i3-msg 'scratchpad show'
```

currently I've bind the key suggested on the official website to these two msgs

``` config
# Make the currently focused window a scratchpad
bindsym $mod+Shift+minus move scratchpad

# Show the first scratchpad window
bindsym $mod+minus scratchpad show
```
