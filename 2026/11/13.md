# systemd

常见的 systemd unit 文件位置：

| 路径                     | 用途                         |
|--------------------------|------------------------------|
| /usr/lib/systemd/system/ | 软件包提供的系统 unit        |
| /lib/systemd/system/     | Ubuntu 上常见的兼容路径      |
| /etc/systemd/system/     | 管理员创建的 unit 和覆盖配置 |
| /run/systemd/system/     | 运行时生成的 unit            |

# create and delete a user

```
sudo adduser alice
```

```
sudo deluser alice
```

## login as different user: 

```
su - alice
```

## give the user privileges

```
sudo usermod -aG sudo alice
```

-a: append
-G: specify the user group

question: I know sudo is a user group. Is it also a specific user?

answer: NO! sudo is a user group, and root is a user

# how to set the color of the prompt?

`PS1='\[\e[1;32m\]\u@\h:\w\$ \[\3[0m\]' `

`\[` and `\]` means the characters inside don't occupy any visible columns, which is important for correct cursor positioning.

`\e`: the ESC character

`[1;32m` : an ANSI SGR sequence that enables bold text and sets the foreground color to green.

`\e[0m` : Reset all text formatting
