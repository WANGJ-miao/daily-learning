# RSS in emacs

Elfeed

some basic operations:

fetch content: gR
set search filter: s
clear search filter: c
open article in a browser: go

``` emacs-lisp
(use-package elfeed
  :ensure t                             ; it means to install this package. By default, use-package will require this package when it executes this config. If you don't want your package to be loaded instantaneously, use :defer t.
  :commands (elfeed)                    ; :commands make an autoload. which means to load this package when firstly execute this command
  :init
  (setq elfeed-feeds
        '("https://planet.emacslife.com/atom.xml" ;example feeds
          "https://nullprogram.com/feed/"
          "https://blog.codingnow.com/atom.xml"
          "https://coolshell.cn/feed"
          "https://skywind.me/blog/feed"
          "http://feeds.feedburner.com/ruanyifeng"
          )))
```
a config in init.el

elfeed-feeds can also be a nested list, like:

``` emacs-lisp
(use-package elfeed
  :ensure t
  :commands (elfeed)
  :init
  (setq elfeed-feeds
        '(("https://planet.emacslife.com/atom.xml" emacs)
          ("https://nullprogram.com/feed/" programming)
          ("https://blog.codingnow.com/atom.xml" programming)
          ("https://coolshell.cn/feed" programming)
          ("https://skywind.me/blog/feed" programming)
          ("https://www.ruanyifeng.com/blog/atom.xml" weekly))))
```

the cdr of the list is tag, which can be used to filter.

+linux: only show the article with linux tag
-harware: exclude the hardware tag

## three ways to discover the feed url

1. look for an rss link(look for the RSS icon, or links labeld "RSS", "Atom", "Feed" or "Subscribe"
2. try command USRLs
- https://example.com/feed/
- https://example.com/rss.xml
- https://example.com/atom.xml
- https://example.com/feed.xml
3. inspect the html source
press C-u to view the source code of a blog's homepage, then search for application/rss+xml, may find:

``` html
<link
  rel="alternate"
  type="application/rss+xml"
  title="My Blog"
  href="https://example.com/feed.xml">
```

I can also inspect a website from the terminal:

curl -Ls https://example.com | grep -Ei 'rss\+xml|atom\+xml'

```
bdw, 这里使用\+而不是+, 是因为在正则表达式中+是一个特殊字符, 表示: 前面的字符或者表达式重复一次或者多次
```

# 为什么emacs一直是单线程的?

1. 一个主要原因是历史包袱. emacs创造初期并不存在多核并行, 它的设计之初就没有考虑到多核并行时候涉及到的竞争问题. 修改行为, 修改接口, 存在很多的兼容性问题
2. 不像是c语言, 把复杂度都暴露给用户, emacs lisp和python把底层操作都隐藏起来了, 所以语言本身需要考虑的事情更多, 所以相比于c, emacs lisp和python会更难处理这种问题
