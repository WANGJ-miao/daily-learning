# bash

``` bash
if [[ ${FZF_CTRL_R_COMMAND-x} != "" ]]; then
if [[ -n ${FZF_CTRL_R_COMMAND-} ]]; then
    echo "warning: FZF_CTRL_R_COMMAND is set to a custom command, but custom commands are not yet supported for CTRL-R" >&2
fi
bind -m emacs-standard -x '"\C-r": __fzf_history__'
bind -m vi-command -x '"\C-r": __fzf_history__'
bind -m vi-insert -x '"\C-r": __fzf_history__'
fi
```

`${FZF_CTRL_R_COMMAND-x}`: parameter expansion in bash. `${variable-default}`

`-n string ` checks whether string is not empty


# some thoughts after talking with AI

It's about what to learn, why I learn, and how to learn.

question: 如果ai能够完成这件事， 我自己研究独立完成它还有意义么？

answer: 有意义！ 这取决于我自己想得到什么？ 我想让这件工作快点完成还是想真正理解背后的原理？ 如果是想让工作快速完成， 那就交给ai吧。 如果是想真正理解背后的原理， 那就需要花时间， 需要自己尽力思考。 ai能理解的当然不能得出我的理解就便的毫无意义。 一个不能真正自己理解原理的人， 在使用ai的时候， 只会成为ai的努力， 没有自主性。 既然自己都已经想清楚了自己学习的目的， 那就别犹豫和质疑自己了， 加油干！
