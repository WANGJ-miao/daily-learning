## Makefile
一般Makefile会分成编译和链接两个阶段写
``` Makefile
app: main.o func.o
    gcc main.o func.o -o app

main.o: main.c
    gcc -c main.c -o main.o #-c表示只编译

func.o: func.c
    gcc -c func.c -o func.o 
```
### Makefile 中定义和使用变量
- 定义:
GXX = gcc
TARGET = app
CXXFLAGS = -std=c++20 -Wall -Wextra
- 使用
app: main.o foo.o
    $(GXX) main.o foo.o -o $(Target)
### := 和 = 的区别
- = 延迟展开
```Makefile
A = $(B)
B = hello
all:
    echo $(A)
```
输出: 
hello
- := 立即展开
```Makefile
A = $(B)
B = hello
all:
    echo $(A)
```
输出:
空
### 自动变量
- $@
当前变量
eg.
```Makefile
app: main.o
    g++ -o main $@
```
- $<
第一个依赖项
eg.
```Makefile
main.o: main.c
    g++ $< -o $@
```
- $^
所有依赖项
eg.
```Makefile
app: main.o foo.o
```
### 模式规则
eg.
```Makefile
%.o: %.cpp
    g++ -c $< -o $@ 
```
这个规则会编译所有以.cpp结尾的文件为同名.o文件
### .PHONY
假命令
常见假命令:
.PHONY: all clean run debug install tags
### 使用wildcard自动寻找源文件
假设目录结构:
```
project/
├── Makefile
├── include/
│   └── foo.hpp
└── src/
    ├── main.cpp
    ├── foo.cpp
    └── bar.cpp
```
```Makefile
SRCS := $(wildcard src/*.cpp)
```
获取所有源文件
```Makefile
OBJ := $(SRCS:.cpp=.o)
```
把所有.cpp替换成.o
