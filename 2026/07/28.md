# 访问条件码
1. 根据条件码的组合, 把一个字节设置为0/1   **SET指令**
2. 条件跳转到程序的某一个地方
3. 有条件地传送数据

## 条件码
- CF
最高位进位标志(无符号溢出)
- OF
溢出标志(有符号溢出)
- SF
符号标志
- ZF
零标志

## SET指令
eg. setl D : D <- SF ^ OF
SF 表示结果是负数还是正数
OF 表示是否有符号操作溢出? 如果是负数, 但是有溢出, 说明原结果是一个正数, 如果是正数, 但是有溢出, 说明原结果似乎一个负数
eg. cmp A, B
1. A < B < 0
2. A < 0 < B
3. 0 < A < B

## 跳转指令
- jmp Label 直接跳转
eg. jmp .L1
- jmp \*Operand 间接跳转
eg. jmp \*%rax
jmp \*(%rax)
- 条件跳转, 例如:je, jl, jg, js, ja, jb

## 条件传送
eg. cmove, cmovg, cmovl ... 
这里c表示conditional, 区分与mov(无条件传送)
在现代处理器上, 条件传送比条件跳转效率更高, 因为更容易预测

# 过程

## 共有特性
### 分配和释放内存
调用Q的时候给Q分配内存, 然后Q返回的时候把这些资源释放
**栈帧**
*结构*          属于哪个过程?
较早的帧            *
多余6个的参数       P
返回地址            P
被保存的寄存器      Q
局部变量            Q
参数构造区          Q
*事实上, 大多数的函数调用都不需要栈帧, 当所有的局部变量都可以储存在寄存器中或者不会调用别的函数的时候就都可以这样处理*
### 传递控制
P调用过程Q, 需要把程序计数器的值先设置为Q的起始地址, 然后Q完成后, 程序计数器的值设置为P调用Q之后的下一条的指令地址
call Q 会把P过程的下一个指令A的地址压入栈帧中, 叫做返回地址, 并把PC的值变成Q的起始地址
ret 则会从栈中弹出A的地址, 并放入PC中
同跳转一样, 调用也分为直接调用和简介调用
call Label          直接调用
call \*Operand      间接调用
bdw PC是计算机中一个通用的概念, 而%rip(instruction pointer)是x86中具体实现这个功能的寄存器
### 传递数据
P给Q传入参数, Q给P返回值

寄存器是唯一一组被所有过程共享的资源
根据惯例, rbx, rbp, r12-r15是被调用者保存的寄存器, 意思是当P调用Q的时候, Q必须保证这些寄存器的值在自己被调用之后和之前是不变的, 

## 数据对齐
原则: 任何K字节的基本对象的地址必须是K的倍数
对于包含结构的代码, 编译器会在字段的分配中加入间隙, 用来保证所有元素都满足对齐需求
例如
```c
struct S1 {
    int i;
    char c;
    int j;
}
```
i, c, j的起始地址分别是0, 4, 8, 而不是0, 4, 5
