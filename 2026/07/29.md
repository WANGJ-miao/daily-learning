# 网络编程
## IP地址
## 因特网域名(domain name)
域名集合形成了一个树状层次结构, 树的节点表示域名, 反向到根的路径形成了域名, 树的根是一个未命名的节点, 向下一层是第一级域名, 包括像com, org, edu, gov...这由非营利组织ICANN定义.
因特网定义了域名到ip地址之间的映射, 直到1988年, 这个映射都是由一个叫HOSTS.TXT的文本文件手工维护的, 从那以后, 这个映射是由分布全球的数据库(DNS, domain name system)维护的.
一个socket是连接的一个端点, 由因特网ip地址和一个16位的整数端口组成, 用address:port表示
一个连接是由它两端的套接字地址唯一确定的, 叫做套接字地址对(socket pair), (cliaddr:port, servaddr:port)
## Web基础
Web客户端和服务器之间的交互用的是一个基于文本的应用级协议, 叫做HTTP(Hypertext Transfer Protocol)
## Web内容
内容是一个MIME(Multiple Internet Mail Extensions)类型相关的字节序列
一些常用的MIME类型:
- text/html
- text/plain
- application/postscript
- image/gif
- image/png
- image/jpeg
Web有两种方式把内容交给用户:
- 取一个磁盘文件, 把它的内容交给客户端, 这个磁盘的内容称作静态内容
- 运行一个可执行文件, 把它的输出交给客户端, 这个输出叫做动态内容
每条由web返回的内容都是与它管理的某一个文件相关的, 每个文件都有一个唯一的名字, 叫做url(Universal Resource Locator)

## http响应中有什么?
1. 状态行
2. 响应头
3. 空行
4. 相应正文
```plain text
HTTP/1.1 200 OK                    ← 状态行
Content-Type: text/html; charset=utf-8
Content-Length: 31                 ← 响应头
Cache-Control: no-cache
Connection: keep-alive
                                      ← 空行
<h1>Hello, world!</h1>             ← 响应正文
```

1. 状态行
包含http版本, 状态码, 原因短语
2. 响应头
告诉浏览器怎么解析这一帧数据
最重要:Content-Type 这一帧数据是什么类型的?
Content-Length有效数据的长度
是否使用内存控制
...
3. 空行
用于区分响应头和相应正文
浏览器会把第一个连续出现两次\r\n后面的内容视作相应正文
4. 相应正文


# javascript
## ESM模块export与import
## ESM与CommonJS
两种javascript的模块组织方式
CommonJS使用module.exports与require()
ESM使用export和import
### 语法具体对比
#### 一个类
- CommonoJS
导出
``` javascript
class UDPReceiver {}
module.exports = UDPReceiver
```
导入
``` javascript
const Receiver = require("./UDPReceiver.js");
```
- ESM
导出
``` javascript
export export class UDPReceiver {}
```
导入
``` javascript
import Receiver from "./UDPReceiver.js"
```
#### 多个内容
- CommonJS
导出
``` javascript
class ACalss {}
function aFunction() {}
const a_variable = 8000;
module.exports = {
    AClass,
    aFunction,
    a_variable
};
```
导入
``` javascript
const {
    AClass,
    aFunction,
    a_variable
} = require("./file.js");
```
- ESM
导出
``` javascript
export class AClass {}
export function aFunction() {}
export const a_variable = 900;
```
导入
```javascript
import {
    AClass,
    aFunction,
    a_variable
} from "./file.js"
```

## javascript 对象参数初始化
``` javascript
constructor(options) {
    this.host = options.host;
    this.name = options.name;
    ...
}
```
但javascript一般不会这么写, 而是直接解析参数的地方做解包
``` javascript
constructor({host = "127.0.0.1", name = "wj"} = {}) {
    this.host = host;
    this.name = name;
    ...
}
```
这里的意思是:直接解包传入的对象, 取出host, name, 传递给类内元素, 如果什么都没传, 就默认传入空{}, 这样就能正常使用默认值, 如果不这么写, 什么都没传的时候会报错
