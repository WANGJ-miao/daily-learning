# 一种代码设计框架
把数据流中的生产者和消费者设计成接口, 通过pipeline连接各种处理模块
Gstreamer 中最基本的对象: GstElement
Pipeline 本质就是一组连接起来的Element
一般流程
``` c
//创建管道
GstElement *pipeline;
pipeline = gst_pipeline_new("my-pipeline");
//添加组件
gst_bin_add_many(pipeline, camera, filter, sink, NULL);
//连接
gst_element_link(camera, filter);
gst_element_link(filter, sink);
//设置管道状态, 开始运行
gst_set_state(pipeline, GST_STATE_PLAYING);
```
## appsrc是什么?
GstElement camera这种元素会自己产生数据
但是大部分时候, 数据不是GStreamer产生的, 需要手动创建一个appsrc(application source)
让appsrc成为pipeline的数据源

## Event Driven Design
``` c
g_signal_emit_by_name(appsrc_, "push-buffer", buffer, &ret);
```
像这一句, 由于GStreamer是用c写的, 它不能像c++一样使用虚函数, 而又不想使用普通函数, 因为这样拓展性很差. 所以最终使用了这样的用事件信号驱动的系统.
