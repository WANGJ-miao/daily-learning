# 编程积累: 学习解析命令行输入参数
1. c 手动解析
``` c
int main(int argc, char *argv[]) {
}
```
其中argc是参数数量
argv是字符串数组
举个例子:
./test hello world 123
那么 argc = 4
argv[0] = "./test"
argv[1] = "hello"
argv[2] = "world"
argv[3] = "123"
**argv[0]永远是程序名称**
手动解析:
``` c
#include <string.h>

for(int i = 1; i < argc; i++)
{
    if(strcmp(argv[i], "-p") == 0)
    {
        port = atoi(argv[i+1]);//atoi: ASCII to integer
        i++;
    }
    else if(strcmp(argv[i], "-d") == 0)
    {
        debug = 1;
    }
}
```
但是atoi不安全
atoi("abc") 返回0, 这样程序不知道是传入了一个非数字还是真的输入了数字0
*推荐使用strtol*
` strtol(const char *str, char **endptr, int base);
str是要解析的字符串, endptr是str从开头开始解析完数字后面的字符串的指针, base是基数, 表示多少进制. 如果是0, 就通过str的格式来判断进制, 0开头, 还是0x开头?其余默认十进制
用法:
``` c
#include <stdlib.h>

char *end;
long value = strtol(argv[1], &end, 10);
if (!*end == '\0') {
    printf("invalid number");
}
```
2. Linux 提供的标准解析函数: getopt() 解析单字符参数
```c
#include <unistd.h>

int getopt(int argc, char * const arg[], const char *optstring);
```
optstring 是字符(+冒号)的组合
如果有冒号, 就表示前面一个选项需要参数
参数是optarg(这是bits/getopt_core.h定义的一个全局变量, 当然, 包含在unistd.h中)
用法:
``` c
#include <stdio.h>
#include <unistd.h>

int main(int argc, char *argv[]) {
    int opt;
    int port;
    int debug;

    while ((opt=getopt(argc, argv, "p:d")) != -1) {
        switch (opt) {
            case 'p':
                port = atoi(optarg);
                break;
            case 'd':
                debug = 1;
                break;
        }
    }
}
```
3. getopt_long() 可解析多字符参数
``` c
#include <getopt.h>
#include <stdlib.h>
#include <stdio.h>

int main(int argc, char *argv[]) {
	int opt;
	int opt_index;
	int port = 0;
	int debug = 0;
	const char* usage_string = "usage: [-d/--debug] [-p/--port port]"; 

	struct option options[] = {
		{"port", required_argument, 0, 'p'},
		{"debug", no_argument, 0, 'd'},
		{0, 0, 0, 0}
	};

	while ((opt = getopt_long(argc, argv, "p:d", options, &opt_index)) != -1) {
		switch (opt) {
			case 'p':
				port = atoi(optarg);
				printf("opt_index: %d\n", opt_index);
				printf("port = %d\n", port);
				break;
			case 'd':
				debug = 1;
				printf("opt_index: %d\n", opt_index);
				printf("debug = %d\n", debug);
				break;
			default:
				printf("wrong argument! Usage %s\n", usage_string);
		}
	}
}
```
``` c
struct option
{
  const char *name;
  /* has_arg can't be an enum because some compilers complain about
     type mismatches in all the code that assumes it is an int.  */
  int has_arg;
  int *flag;
  int val;
};
```
struct option 
1. name:长参数名字 
2. has_arg:是否有参数 使用宏变量
#define no_argument		0
#define required_argument	1
#define optional_argument	2
3. flag
这个名字怪怪的, 实际表示:如果匹配上了, val写在哪里?是返回到一个固定的变量中?还是作为getopt_long的返回值返回?
如果返回到一个固定的变量中, 就填入这个变量的地址
如果要作为getopt_long的返回值, 就填入空指针, 就是0或者NULL

*一般, 会把长参数名字的返回值写成单字母, 这样就能统一处理长短参数了*

5. cpp 不想引用库, 一般会写一个小小的argParser
``` cpp
class Args
{
public:

    Args(int argc,char** argv)
    {
        for(int i=1;i<argc;i++)
        {
            args_.push_back(argv[i]);
        }
    }


    bool has(std::string key)
    {
        return std::find(
            args_.begin(),
            args_.end(),
            key)
            != args_.end();
    }


    std::string get(std::string key)
    {
        for(size_t i=0;i<args_.size();i++)
        {
            if(args_[i]==key && i+1<args_.size())
                return args_[i+1];
        }

        return {};
    }


private:

    std::vector<std::string> args_;
};
```

# 编程积累: 学会看const
从变量名开始, 先看右边, 后看左边
例: char * const arg[];
arg是一个数组, 数组的数据类型是char * const
const 修饰的是左边最近的东西, 如果左边没有东西, 就修饰右边的
例: char * const (*p)[10];
p是数组指针, 指向的是有10个元素的数组, 数组的元素是常量char指针
