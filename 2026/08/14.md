PLT(过程链接表) 为调用动态函数准备一小段跳板代码 不保存地址
GOT(全局偏移量表) 保存最终地址的表
interposition库打桩

2. 链接时打桩, 使用wrap, 将所有未定义的函数前加上\_\_wrap\_, 这样就能自己定义\_\_wrap\_function\_name, 同时可以适应\_\_real\_functino\_name代替原来的function\_name,

## ECF Exception Control Flow 异常控制流
### 异常
异常的分类
- 中断
- 陷阱
- 故障
- 终止
Linux 系统中的故障和终止
- 除法错误(异常0) Floating exception
- 一般保护异常(异常13) Segmentation fault 一般是因为程序引用一个未定义的虚拟内存区域, 或者程序尝试写一个只读的文本段
- 缺页(异常14) 访问虚拟地址, 但是还没有被映射到实际的物理地址. 其实大多数情况不是错误, 懒加载会利用这个特性
- 机器检查(异常18) 检测到致命的硬件错误
Linux 系统中的系统调用, 包括读写文件, 创建进程
每一个系统调用函数都有一个唯一的整数编号, 对应于内核中的一个跳转表offset(不用于异常表)

## 进程
**计算机历史上最为成功的概念之一**
经典定义:一个执行中程序的实例
进程提供给程序的两个假象
1. 一个独立的逻辑控制流, 好像我们的程序独自占用整个处理器
如果两个逻辑流在时间上有重叠, 两者称为并发流(concurrent flow), 这一现象成为并发(concurrency), 不同进程轮流运行的概念称为多任务(multitasking), 一个进程执行它的控制流的每一个时间片段称为时间片(time slice), 因此, 多任务也称为时间分片(time slicing)
如果两个控制流发生在两个不同的处理器上, 就称之为并行流(parallel flow), 他们并行运行(running in parellel)
**并行是并发的真子集**
2. 一个私有的地址空间, 好像我们的程序独自占用整个内存空间

### 系统调用的包装函数
示例
``` c
void unix_error(char *msg) {
	fprintf(stderr, "%s: %s", msg, stderror(errno));
}

pid_t Fork() {
	pid_t pid;

	if ((pid = fork()) < 0) {
		unix_error("fork error");
	}
	
	return pid;
}
```
