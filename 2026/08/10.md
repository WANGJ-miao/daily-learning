# 人成长意味着越来越自私吗?(起因是我认为人成长中需学会不在意他人的看法)
但是(完全不在意他人想法)这个想法不可能实现的. 
例如我在意涵姐的想法, 这是我无论如何都欺骗不了自己的事实. 
如果强行假装自己不在意, 这是在扼杀自己的情感, 也是在切断与他人的联系, 
我发现自己本来就不是谁的想法都在意, 在意的程度也都不一样, 
例如我穿着有复旦logo的队服在高速公路服务区被一个小朋友的家长说装x, 我发现自己完全不care, 哈哈哈
所以人在成长的过程中应该学会的是分析自己在意哪些人的想法?为什么在意?
学会做到勇敢地接受自己被他人评价影响的心情, 
但是在心情与行动之间停一停, 
不要让他人的评价直接影响自己的行为.
他人的评价不应该成为自己幸福感的来源, 那是不自由的幸福, 
自由的幸福感应该来源于自身, 来源于自己在共同体中主动贡献, 
共同体是一个自由, 抽象的概念, 它可以是两个人之间, 可以是一个团队, 
可以是一个民族, 甚至可以是整个宇宙.
总是我想说人成长不应该变得自私, 而是应该变得勇敢(敢于面对自己的情感, 敢于基于自己的意愿行动)

# 目标文件
三种形式
- 可重定位目标文件
- 可执行目标文件
- 共享目标文件(一种特殊的可重定位目标文件, 可以在加载或运行时被动态地加载进内存并链接)
编译器和汇编器生成可重定位目标文件
链接器生成可执行目标文件

## ELF可重定位目标文件
ELF头(ELF header)
一堆节(a bunch of sections)
    - .text(已编译程序地机器代码)
    - .rodata(只读数据, 例如printf中的字符串和开关语句的跳转表)
    - .data(已初始化的全局和静态C变量)
    - .bss(未初始化的全局和静态变量, 不占用实际空间, 只是一个占位符, 可以把它看成是Better Save Space的缩写)
    - .symtab(符号表, 存放程序中定义的和引用的函数和全局变量的信息)
    - .rel.text ?
    - .rel.data ?
    - .debug(一个符号调试列表, 只有使用-g参数调用编译器的时候才会生成这张表)
    - .line(.text中机器码和源文件中行号的位置映射, 只有使用-g参数调用编译器的时候才会生成这张表)
    - .strtab ?
节头部表(section header table)
## 符号表
符号表是由汇编器使用编译器输出到汇编文件.s中的符号构造的, 这张表是一个个条目组成的数组
每个数组的格式:
``` c
typedef struct {
    int name;               //string table offset, string table 就是一个用\0分隔的一个连续字符串
    char type:4,            //function or data
         binding:4;         //local or global
    char reserved;          //unused "现在好像表示可见性
    short section;          //section header index(代表这个在什么类型的section中)
    long value;             //section offset(在这个section中的偏移位置) or absolute address
    long size;              //object size in Bytes
} ELF64_Symbol
```
