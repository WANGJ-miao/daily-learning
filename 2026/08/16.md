## 发送信号
Unix系统提供了大量发送信号的机制, 所有的机制都是基于进程组(process group)这个概念
每个进程都只属于一个进程组, 有一个正整数进程组ID标识, 默认父子进程属于同一个进程组
1. 可以使用set-pgid函数来改变自己或其他进程的进程组
``` c
#include <unistd.h>
int setpgid(pid_t pid, pid_t pgid);
```
2. 使用/bin/kill程序发送信号
3. 从键盘发送信号 (Unix shell使用job这个改变来表示为一条命令行求值而创建的进程)
4. 使用kill函数发送信号
``` c
#include <sys/typesl.h>
#include <signal.h>

int kill(pid_t pid, int sig);
```
如果pid大于0, 则发送信号给进程pid
如果pid小于0, 则发送信号给进程组-pid中的每一个进程
5. 使用alarm函数发送信号
进程可以使用alarm函数向自己发送sigalrm信号
``` c
#include <unistd.h>
unsigned int alarm(unsigned int secs);
```
返回前一个闹钟的剩余秒数

可以使用signal函数修改和信号相关联的默认行为
例外: sigstop sigkill 它们的默认行为不能修改
``` c
#include <signal.h>
typedef void (*sighandler_t)(int);

sighandler_t signal(int signum, sighandler_t handler);
```
