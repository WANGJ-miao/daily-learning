# Unix I/O
- 打开文件. 一个程序通过要求内核打开相应的文件来宣告访问某个I/O设备.  内核返回一个非负整数, 叫做描述符, 它在后面的左右操作中标识这个文件
- Linux Shell 创建的每一个进程开始的时候都有三个打开的文件. 标准输入(0), 标准输出(1), 标准错误(2). 头文件unistd.h中定义了STDOUT\_FILENO, STDOUT\_FILENO, STDERROR\_FILENO
- 改变当前文件位置, k 从0开始的地址偏移量
- 读写文件. 当k大于m(文件大小)的时候, 会触发一个EOF(End of File)条件.
- 关闭文件 内核会释放文件打开时创建的数据结构, 并将描述符恢复到可用的描述符池中

#!/bin/bash

tmux new-window -t $SESSION -n run

tmux attach -t $SESSION
