# 编程积累
``` cpp
template<typename _Tp, typename... _Types> // 第一个是一个类型参数, 第二个是一维类型参数
constexpr bool //返回值是bool, 并且constexpr表示尽量编译期解决这个函数返回值
holds_alternative(const variant<_Types...>& __v) noexcept // TODO noexcept是什么
{
  static_assert(__detail::__variant::__exactly_once<_Tp, _Types...>,
        "T must occur exactly once in alternatives");
  return __v.index() == std::__find_uniq_type_in_pack<_Tp, _Types...>();  // variant 内部会维护当前的类型是第几个, 
                                                                          // 这里返回当前的类型序号和Tp_的序号是否一致
}
```

## template
template 参数可以填:
1. 类型参数 typename T / class T 这时候两者等价, 都表示一个可选的类型
2. 值参数 例如: `template<int N >
3. 模板本身 
模板可以有多个参数, 顺序很重要, 按序给值
模板参数包 template<typename... Types_>
``` cpp
// Return the index of _Tp in _Types, if it occurs exactly once.
// Otherwise, return sizeof...(_Types).
template<typename _Tp, typename... _Types>
constexpr size_t
__find_uniq_type_in_pack()
{
  constexpr size_t __sz = sizeof...(_Types);
  constexpr bool __found[__sz] = { __is_same(_Tp, _Types) ... };
  size_t __n = __sz;
  for (size_t __i = 0; __i < __sz; ++__i)
{
  if (__found[__i])
    {
      if (__n < __sz) // more than one _Tp found
    return __sz;
      __n = __i;
    }
}
  return __n;
}
```

# cmake 语法
1. 变量
    1. 定义变量
    set(VERSION 17)
    set(NAME wangj)
    2. 读取变量
    ${NAME} 变量展开
    3. 删除变量
    unset(NAME)
    4. 列表也是变量
    set(SOURCES 
        main.cpp
        foo.cpp
        bar.cpp)
    add_executable(main SOURCES)
    cmake中的列表实际上就是分号分割的字符串
5. 字符串和参数
    字符串不需要加" 但是如果中间有空格就需要加引号, 不然会被识别成多个参数
6. 条件语句
    ``` plain text
    if (condition)
        ...
    elseif (condition)
        ...
    else()
        ...
    endif()
    ```
    判断布尔变量
    ``` cmake
    set (BUILD_SERVER on)

    if (BUILD_SERVER)

    endif()
    ```
    常见真值:

    常见假值:

    AND OR NOT
