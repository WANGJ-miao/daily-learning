# cpp std::promise std::future
线程间结果传递机制
常见流程:
``` cpp
int main() {
    result_t result;
    std::thread t([&]() {
        result = do_work();
    });
    t.join();
    show_result(result);
}
```
这里涉及的问题: 1. 需要共享变脸, 需要有锁保护 2. 不知道什么时候结果好了
std::promise 表示承诺后面会填值, std::future 是promise得到的结果
``` cpp
#include <thread>
#include <future>
#include <iostream>

int main() {
	std::promise<int> p;
	std::future<int> f = p.get_future();

	std::thread t([&p]() {
			std::cout<< "working\n";
			p.set_value(1);
		});

	std::cout<< "waiting\n";

	int value = f.get();
	std::cout<< "value: " << value << "\n";

	t.join();
	return 0;
}
```
