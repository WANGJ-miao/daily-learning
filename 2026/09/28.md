# gpu programming
cpu: 怎么写得更快
gpu: 怎么把一个大任务拆分成很多彼此独立的小任务?

cuda 程序同时运行在cpu和gpu上
cuda 把cpu叫做host, gpu叫做device
``` c
int main() {
    ...
}
```
这种运行在cpu上
``` c
__global__
int add(...) {
    ...
}
```
这种运行在gpu上
运行在gpu上的函数叫做kernel核函数
## grid block thread
Grid -> Block -> Thread
``` c
int i = blockId.x * blockDim.x + threadId.x
```
## kernel launch
``` cpp
vector_add<<<blockx, threads>>>(A, B, C, N)
```

## a classic cuda process
1. cpu create thread
2. gpu malloc memory
3. cpu ram -> gpu vram
4. gpu kernel calculation
5. gpu vram -> cpu ram
6. cpu look up the outcome
use cuda api to express:
1. malloc / normal array
2. cudaMalloc
3. cudaMemcpy Host -> Device
4. kernel<<<...>>>()
5. cudaMemcpy Device -> Host
6. cudaFree
