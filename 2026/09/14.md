# python
comparison:
is vs ==
"is" checks whether two name refers to the same object
"==" checks whether their value are the same
"is" is often used in case of None:
``` python
if a is not None:
    pass
```
that is because None is an unique object in python

logical operators:
- python:
    and or not
- c:
    && || !
python中应该尽量避免使用可变对象作为默认参数, 因为默认参数对象只有在函数定义的时候创建一次, 不同的实例可能共享同一个对象
