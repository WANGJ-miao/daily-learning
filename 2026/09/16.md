## pytorch
ToTensor() function in pytorch does three things
1. change the image to a PyTorch tensor
2. converts pixel values from integers in [0, 255] to floating-point values is [0, 1]
3. change the dimension order from (H, W, C) to (C, H, W)
however, a more modern api constructs the whole process more explicitly.
in PyTorch torch.optim.optimizer() allows parameter-groups, each group can use different configurations.
for example:
``` python
torch.optim.SGD(
    [
        {'params': params_1x},
        {
            'params': net.fc.parameters(),
            'lr': learning_rate * 10
        },
    ],
    lr=learning_rate,
    weight_decay=0.001
)
```

# SiZheng Project
Human Physiological Activity -> Sensor -> Raw Data -> Feature Indicator -> Blood Pressure Estimatation
Goal: Estimate SDP and BDP
    - SDP: 收缩压
    - DBP: 舒张压
Thought: Use other relative physical signal to indirectly estimate SDP and BDP. 
So there are terminology like ECG PPG SCG BCG
ECG: Electrocardiogram 心电图
PCG: 心音图
SCG: Seismocardiography 心震图
    we can get three main feature in SCG: AO AC LVET
    AO: Aortic Valve Opening
    AC: Aortic Valve Closure
    LEVT: Left Ventricular Ejection Time = AO - AC
BCG: Ballistocardiography 心冲击图
    心脏射血导致的身体的反作用
    BCG 中J锋的最为明显, 可以提取J锋位置, 幅度, 周期作为学习的BCG特征
PPG: Photoplethysmography 光电容积脉搏波
血管里的血容量随着时间变化, 因此对光的吸收能力也会变化, 光电二极管检测到I(t), 这就是脉搏波
ECG + PPG 产生一个重要的指标: PAT Pulse Arival Time 脉搏到达时间. 一般来说血压越大, 血管越紧, 脉搏波速度越大, 传播时间越小
``` plain_text
                   心脏
                     │
          ┌──────────┼──────────┐
          ↓          ↓          ↓
        电活动    机械运动     射血
          │          │          │
         ECG        SCG        BCG
                                │
                           血液传到外周
                                │
                               PPG
```
