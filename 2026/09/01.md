# 计算机基础知识
cpu缓存管理
以"缓存行"为单位, 通常是64字节
eg.
struct Counter {
    int a;
    int b;
} c;
Thread a:
    c.a = 1;
Thread b:
    c.b = 1;
c.a 和 c.b可能在同一个cache line
假设底层结构是这样的:
                 RAM
                  │
              Shared L3
             /         \
          Core 0       Core 1
          L1/L2        L1/L2
cpu的每一个核都有自己的L1缓存, 所以假设a线程跑在core 0上, b线程跑在core 1上, 然后b线程要在core 1上修改c.b
cpu 不希望每次都访问RAM, 所以会把c.a附近一整块cache line搬进自己的缓存中,
如果只是读取, 这不会有什么问题
但是当要写的时候, b线程在core 1上修改了c.b, cpu必须保证所有核看到的数据都是一样的(Cache Coherence), 所以会通知所有包含c.b这一cache line的核都去更新数据, 宣布以前的cache作废, i.e. cache invalid.
