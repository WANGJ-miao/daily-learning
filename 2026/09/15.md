# Stochastic Gradient Descent SGD 随机梯度下降
Split the training samples into several batches.
Stochastic comes from " choosing random batch to update weights "
Backpropagation calculate gradients
SGD uses those gradients to update parameters
One small terminology detail: technically, one-sample SGD, mini-batch SGD, and full-batch fradient descent are different. But dl code often uses torch.optim.SGD with mini-batches, so"SGD" ommonly refers to the optimizer rule rather than literally requiring one sample at a time

# network training
in pytorch, a model can be in two main modes:
net.train() # training mode
and net.eval() # evaluation mode
most layers behave excatly the same in both modes. but some layers behave differently, expecially:
nn.Dropout
nn.BatchNorm1d
nn.BatchNorm2d
nn.BatchNorm3d
dropout: randomly stop some neron's output (in order to make the network robust)
while doing dropout, the output decrease cause the num of neurons decrease. so pytorch compensate for this by multiplying the output
## The typical steps of training
``` plain_text
zero_grad()         # clear previous gradients
forward()           # calculate predictions
loss                # calculate loss
backward()          # calculate gradients
step()              # update parameters using gradients
```
