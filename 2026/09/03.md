# 编程积累
bash 语法
$ 表示取变量值, 或者说展开
- name 普通变量
name=alice
echo "$alice"
- 位置参数 $1, $2...表示脚本或者函数收到的第一个, 第二个参数
- 特殊参数 $@, $\*, $#, $?, $$...
  - $0：脚本名，或当前 shell/命令入口名
  - $1 到 ${9}：第 1 到第 9 个位置参数
  - ${10}、${11}：第 10 个及以后参数，10 以上必须加花括号
  - $#：位置参数的个数
  - $@：所有位置参数
  - $\*：所有位置参数
  - $?：上一条命令的退出状态
  - $$：当前 shell 进程 ID
  - $!：最近一个后台任务的 PID
  - $\_：上一条命令的最后一个参数，或 shell 启动时的命令路径，语义相对复杂，少依赖它
## 为什么bash变量需要加双引号?
因为bash在展开变量之后, 还会做两件危险的事情
- 词分割, 按照空格, tab, 换行把一个值拆成多个参数
- 路径名展开, 把\*, ?, [a-z]当成通配符展开成文件名 [a-z]这个通配符是什么意思?怎么转换成文件名?
