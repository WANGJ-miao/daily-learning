# gpu
ptx: parallel thread execution -> nvidia 定义的一种虚拟gpu语言
我感觉有点像c世界的汇编代码, 只不过c中的汇编代码就是直译成二进制, 但是ptx会根据不同的架构生成不同的二进制, 
也就是说c汇编中架构区分再汇编之前, ptx汇编中架构区分在于ptx之后
ptxas: ptx assembler , responsible for translating ptx to specific gpu machine code on certain arch
PTX: virtual ISA
SASS: real NVIDIA GPU ISA
最后gpu machine 会装在cubin这个可执行容器里
最后和cpu分路生成的机器码结合成host上的可执行文件
JIT: just-in-time compilation
`compute_? sm_? 分别指ptx和real_arch的版本
