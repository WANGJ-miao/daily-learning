laplace是在找系统的自然模式, 系统天生喜欢e^st这种形式

    我进入战队的算法组, 主要负责自瞄功能: 解放操作手双手, 自动瞄准装甲板. 这是我没做过的工作, 要学习很多新的东西, 学习在linux上工作, 使用opencv库, 学习计算机视觉模型, ros2... 刚进战队的时候学习过程依然很艰难, 那时候还没用过ai agent, 自己一行行读代码, 一点点问ai, 但是当自己真的搞懂整个系统是如何工作起来的, 每一个组件是怎么拼装起来的, 带给我的快乐和影响又是及其深远的. 总之, 从工程师计划到战队内, 我一直在不断学习, 不断收获快乐.

    1. 这是一个很累, 很耗时的比赛, 需要投入大量的时间精力. 我曾经多次在累的不行的时候和ai聊与这个比赛相关的问题: 怎么平衡战队工作和学习, 应该怎样调整自己的作息... 我觉得参加这个比赛让我在学校中体验了每个进入社会的人都会遇到的困境: 如何平衡工作与生活的平衡. 以前经常在英语阅读中做到相关的阅读理解, work-life balance, 但是我对它从来没有实际的感受, 直到我经历了一年的战队生活. 我提前发现了自己是一个工作狂, 有压榨奴役自己的倾向, 对于没做完的工作, 不做完不睡觉, 也提前感受到了这一倾向带来的问题, 作息不规律, 昼夜颠倒, 精神不佳, 效率低下. 我终于意识到了work-life balance的重要性, 以及爱惜自己身体的重要性.

过去的一年对我的影响远超我的想象, 学到了很多知识, 收获了很多人生体验. 希望更多真正对工科感兴趣的同学参加工程师计划, 加入星云ega战队, 你们不会后悔的. 感谢大家的倾听

## Sequence
python的一个抽象接口
from typing import Sequence
意思是一个可以按顺序访问的容器
list: [1, 2, 3]
tuple: (1, 2, 3)
string: "abc"
这些都是Sequence

python 函数定义
``` python
def add(a, b):
    return a + b
```
1. 加上类型提示:
``` python
def add(a: int, b: int) -> int:
    return a + b
```
2. default argument
``` python
def train(epoch: int, lr: float = 0.01):
    pass
```
3. * 强制关键字参数
``` python
def create_tensor(shape,
                  *,
                  dtype=None,
                  device=None):
    pass
```
* 之后表示强制使用关键词参数, 例如:
正确:
create_tensor((1, 2), dtype=int, device=cpu)
错误:
create_tensor((1, 2), int, cpu)
